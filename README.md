# Delicatessen Soares Landing

Restaurante:

Crie uma landing page moderna e responsiva para um restaurante chamado Delicatensse Soares 

A página deve estar em português-BR e conter:

- Banner principal com imagem de comida e frase chamativa

- Apresentação do restaurante (história ou conceito)

- Seção “Delícias da Casa”

- Seção “Mais Pedidos”

- Cardápio resumido

- Depoimentos de clientes

- Localização

- Botão de reserva via WhatsApp

- CTA destacando promoções ou experiência gastronômica

- Rodapé completo

O design deve seguir o estilo: Moderno, tecnológico , com cores baseadas em: Laranja, vermelho, preto como primaria, branco e amarelo como secundária, texto todo em preto. As imagens e logo de favicon eu te forneci, adicione animações 3D no site, animação de troca  de página, efeitos luminoso sobre fotos e Otimize todo o site para que ele apareça perfeitamente no mobile.

O ambiente do restaurante é: Iluminação quente

A página deve transmitir: Modernidade, Sofisticação, aconchego

Inclua textos persuasivos e realistas: DELlCATESSEN SOARES

Sabor, qualidade e aquele prazer de encontrar tudo o que você procura em um só lugar.

Na Delicatessen Soares, cada detalhe foi pensado para tornar sua experiência mais agradável, desde a escolha dos produtos até o momento de levar para casa aquilo que você gosta.

Um espaço para quem valoriza qualidade, praticidade e bons sabores, seja para o dia a dia, para aquele momento especial ou simplesmente para se permitir uma pausa e aproveitar algo que realmente vale a pena.
